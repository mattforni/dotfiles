# Learned Rules: assist:plan-venture

Corrections and patterns from real runs. Read on every invocation. The founding run is the 2026-07-20 session that repositioned and renamed the practice to Atelic.

- **Treat governing docs as drafts in direction sessions.** The roadmap-from-existing-plan draft was rejected twice before the from-scratch rebuild produced the real answers (category moved to "gets you found and proves it"; brand moved to Atelic).
  - How to apply: rebuild from zero, generate options from evidence and neutral frames, and check whether you land in the same place. Landing somewhere new is the exercise working.

- **When the user reports invisible output, end turns with plain text.** Some clients collapse assistant prose that precedes an AskUserQuestion into "Thought for Ns" rows, so the user answers questions blind.
  - How to apply: present maps, slates, and anything with tables as a plain-text final turn with no trailing tool call, and take the answer in chat. AskUserQuestion previews are a partial fallback, not a fix.

- **Renames cascade further than they look.** The 2026-07-20 brand rename touched folders, GitHub repos, git remotes, Linear team key and workspace name, plugin marketplaces and their registrations, the MCP server name and every skill's allowed-tools, Gmail labels, Drive folders, the calendar labels doc, TAXONOMY, gitignores in two repos, GC paths, the memory store's project-path key, and the legal entity.
  - How to apply: sweep with grep, update live pointers, leave historical and legal documents truthful until the legal rename lands, and put everything that cannot be done in-session on a single tracked checklist issue.

- **Founder meaning may overrule the naming rubric, with costs priced.** The brand specialist scored Atelic worst on paper; Forni chose it anyway for meaning and room to grow, and the right response was pricing the referral tax (pronunciation lock, tagline carries the category) rather than re-arguing the rubric.
